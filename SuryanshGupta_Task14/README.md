In this task, I have created a JavaScript program that performs various operations on a given number, including finding the sum of its digits, checking if it is a Armstrong Number, if it is a prime number, and printing all its factors.

Firstly, i have created two files index.html and script.js. In index.html, inside body tag use <script> tag and using src to link script.js.

In script.js, first using let defined three variables as n, i, s=0. Now for calculating sum of first n numbers used the for loop and inside it use s = s + i. So after each iteration the sum value will increase. When the loop ends the variable s having the sum of first n numbers and using console.log() we print it.

Now for printing the table of n, for it using let defined variable product = 1. Then used for loop, inside it in each iteration doing product = n * i, it means each time multiplying n with the i (iteratiobn) value and printing each iteration using console.log() in table form.

Now for checking prime number, first use if statement, if(n===1) then it is not a prime number as 1 is not a prime number. Now reassigned i = 2 and defined new variable c = 0. Now, using while loop use condition as i <= n (that means run till i is less than n) inside it use if(n%i===0) inside it increment c by 1, after if increase the value of i by 1. The logic behind n%i===0 is that the prime number is divisible by 1 and itself only. As we are starting from i=2 so if that number is a prime number then c will increment only by 1, if not then c value is more than 1. After while loop use the condition if(c===1) then n is a prime number else n is not a prime number.

Now, we want the factors of n, so using let defined variable j = 1. Then used the while loop with condition as j<=n inside it use if statement with condition as n % j ===0 the logic is that if the remainder = 0 then it will be its factor. So, inside it print the factor using console.log(), after it increment the value of j by 1.

Now, sum of all digits of a number. For this, using let defined three variables as digit, m=digit, sum=0. Now, using while loop with condition as digit != 0 inside it doing sum=sum+digit%10 and reducing digit value using division by 10 with Math.floor value to give value in non-decimal form that is less than or equal to digit. The logic is that in each iteration as digit%10 add to sum so the last digit will add and after that in division that digit will disappear, this will continue till all digits are over, then using console.log() print the sum of digits.

Now, for checking Armstrong number. For this, using let defined two variables number, num=number. And reassign m=number, sum=0, c=0. Armstrong is the number in which sum of digits raised to the power of total digits of the number equal to that number. First for checking total digits, use while loop with condition as m!=0 inside it on each iteration increment c by 1 and decreasing m by doing Math.floor(num/10) so that get the non-decimal number and c will contain total number of digits. Now for adding the digits, again use while loop with condition as num!=0 inside it doing sum=sum+(num%10)**c this means adding the digits raised to the power of total number. After that, reducing num as num=Math.floor(num/10) to get non-decimal number which is less than or equal to num. After while loop, if sum===number then using console.log() print number is a Armstrong number, else number is not a Armstrong number.
