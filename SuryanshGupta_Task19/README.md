In this task, I developed a web application that allows users to browse and book services. The application have a user-friendly interface with a navigation bar, a section to display added items, and another section to browse and select services. The user should be able to add services to their cart and book them.

For this task, I created three files index.html, style.css and script.js. In index.html, link the style.css using <link> tag inside head tag. Inside the body tag, link the script.js using <script> tag.
