In this task, I created a react application for an online shoe store where users can browse through a variety of shoes and add them to their shopping cart. It also allow users to add items to their cart or remove them, this is implemented using useState hook in React to manage the state of the cart.

For this, I opened the terminal in VS Code and write npm create vite@latest then enter project name, choose react then JavaScript and ESlint then the folder is created then open src, inside it open the App.jsx delete the already written content, clear the App.css and index.css. 

In App.jsx, inside return create react fragment inside it create a div with className as app which contain the div and main tag. The div tag contains logo and navigation bar with className as navbar, for its styling, use display as flex with some background-color, gap, and padding. Inside it, create a div class name as logo, inside it use img tag and placed the logo with width as 60px. After this div create a unordered list, which contain three navigation links i.e., Home, Categories, About Us, for its styling, use display as flex, align-items as center and some gap; for links use text-decoration as none, color as black, and font-weight as bold.

Now created a main tag with className as content for its styling used display as grid with two columns, align-items as start, with some gap and padding, this contains one section and aside. For section, give className as product-section. Inside it, create a div with className as shoe-products, this div contains the various shoes products, for its styling used display as grid with 2 columns with some gap. Inside it, map the each product from the products array that is at the top, inside it create anpther div with className as product-card for its styling used width 50% with border-radius, display as flex with direction as column and when the mover hover it the card move forward for its used transform scale(1.05) and key i.e. product id, it contains image that has the product image with style width as 100% with height as 250px and display as block and another div with className as product-info style display as flex with direction as column with some gap, border-radius, background-color and padding-bottom which contains the product name, price and add to cart button on click it the item added to the cart for its styling used background as transparent, with border, padding, border-radius and align-self as center, on hover it the background-color changes.

Now created aside with a class name as cart-section for its styling give min-height, padding, background-color, and border-radius. Inside it, write the heading and two divs. First div with className as cart-items. Inside it map the added item to the cart, then cfeated a div with className as cart-item and key as item id style with display as flex, align-items as center with some gap and padding, inside it put the item image then created a div with className as cart-details which contain the heading and the amount of the added item. Next, created another div with className as quantity style display as flex, align-items as center, inside it there are two buttons(for its styling give some padding, background-color, border-radius when hover then background color changes) and one span; first button for decrease quantity then the item quantity then second button for increase the quantity and on clicking the button particular item quantity got increase or decrease. Now, second div with className as cart-total style text-align as center with some margin-top. This contains the heading as Total that will show the total amount of the items that are in cart.

Now above return create the products array that contains object with field as id, name, price and image. Then used the useState hook write the syntax of useState cart stores the current value, setCart updates the value of cart and useState([]) initializes cart as an empty array. now created a variable addCart that will add the item to the cart used arrow function pass product as the parameter, inside it, create a variable existingItem that find that is the product already exist by matching id. If exist then using setCart map the item in the cart with same id increase the quantity by 1, else, add the item to the cart with quantity as 1. Now create another variable name as increaseQty for increasing the quantity by 1 used arrow function with parameter as id then using setCart map the item if the id is equal to the current item id then rest same(...item is spread operator instead of writing same thing we keep rest property) only increase the quantity by 1. Same for decrease quantity using setCart map the item if the id is equal to the current item id then rest same only decrease the quantity by 1 and filter it i.e. only keep the item whose quantity is more than 0. Then in total variable, using reduce call each item that are in cart and using arrow function pass sum and item as parameter then calculate the total by multiplying item price with quantity, initialize sum with 0. And we call these functions in the code and performed the operations.

Through this task, I understand how to use useState hooks in React to update the item and to manage content in the webpage.
