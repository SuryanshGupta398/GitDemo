In this task, I created a React component for card that displays information passes as props. I developed a reusable card component that render details from an array objects passed as props.

For this, I opened the terminal in VS Code and write npm create vite@latest then enter project name, choose react then JavaScript and ESlint then the folder is created then open src, inside it open the App.jsx delete the already written content, clear the App.css and index.css. And install the Tailwind CSS from website and import in the CSS. Also, inside src create new folder named component inside create new file named Card.jsx.

Now, I opened the App.jsx above return statement created a variable named as information of array type containing objects, each object contain id and image to be displayed on the card. Next inside return, I used the React Fragment(<>...</>) inside it create a div style the whole page as black and serif font-family. Inside div, created a heading with styling as text-xl, text-center, violet colour, bold font, and padding top. After that, called the Card component and passed the information array through props.

Now inside Card.jsx, created a function name Card and passed the parameter data which is having the information array that is passed as props. Next inside return, created a div display as grid with 3 columns in large screen and 1 column in small screen with some gap and padding, text as center, and text colour as violet. Inside it, used the map() method to iterate over the array and generate a card for each object, used an arrow function inside it created a div with size-60, padding, with animated-border and animate-gradient.To create the animation, I opened the index.css inside it import tailwindcss then inside @theme directive define a custom animation using --animate-gradient with value as gradient(animation name), animation time, smoothness, how much time it runs. I used @keyframes with animation name to define how gradient background position changes over time, like from 0% 100% to 100% 0%.Then outside the theme, I created the animated-border class using background as linear-gradient() to top right with color as red, blue, yellow, green, red, blue next define the background-size to make the gradient movement visible; and passed key as item id or index of the item. Inside it, created another div which is for each card styled as background black, height as full, some padding, display as flex with direction as column with some gap. Inside it, there is img tag for image with src as particular item image as we are mapping each item with styled as w-full, h-24 and object-contain. Then the heading as Card Number, then the the small description.

Through this task, I understand how to use the props in React application to create reusable components or feature, how to use map() method to display multiple cards from array of objects and how to create animated gradient borders using custom Tailwind CSS animations.

To run this project, open it in VS Code open the task-26 using cd task-26 then install node_modules using npm i then in terminal write npm run dev, then the webpage shows the different cards with gradient border.
