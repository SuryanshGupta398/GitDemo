In this task, I have created a JavaScript program that checks whether a given number is odd or even.

Firstly, I have created two files index.html and script.js. In index.html, inside body tag use <script> tag and using src link to script.js.

In script.js, using let create four different variables, two as num1 and num2 for storing input variables and two as remainder1 and remainder2 for storing the calculation of num1 % 2 and num2 % 2 respectively. 

I was using num1 % 2 and num2 % 2, as if the number is divisible by 2 then it is even and its remainder will be 0. Otherwise, the number is odd and remainder is not 0.

Then using if else statement, I check if remainder1 == 0, then using console.log() print that the number is even. Otherwise, print the number is odd. 

Then again using if else statement, I check if remainder2 == 0, then using console.log() print that the number is even. Otherwise, print the number is odd. 

To run this project, open it in VS Code install the Live Server extension. After that, on bottom right corner click Go Live then the browser window will open right click on it then there is option Inspect click on it then on top left there is option Console click on it then the output will display there.
